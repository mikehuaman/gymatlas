# Gym Atlas

Web app estática con mapa interactivo del gimnasio, inventario de máquinas y rutinas.

## GitHub Pages

En **Settings → Pages**, selecciona **Deploy from a branch**, rama `main`, carpeta `/ (root)`.

La URL esperada es `https://mikehuaman.github.io/gymatlas/`.

## iPhone / iPad

Abre la URL en Safari → Compartir → **Añadir a pantalla de inicio**. La app incluye manifest, iconos, modo standalone y service worker.
